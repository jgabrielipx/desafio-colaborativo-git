# Calculadora de Média

Projeto em grupo da disciplina Design Profissional na UDF, com o objetivo de praticar Git e GitHub.

## O que faz
Recebe o nome do aluno(a) e  em seguinte as 3 notas, calcula a média e mostra "Aprovado" (média >= 6) ou "Reprovado".

## Tecnologias
HTML, CSS e JavaScript

## O que praticamos
- Trabalho em equipe com branches e pull requests
- Resolução de conflito de merge

## Como rodar
Baixe o repositório e abra o index.html no navegador.
